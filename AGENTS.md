# UrlWatcher

## Commits

After completing every individual task — whether that is an entire user prompt or a clearly separated sub-task within a larger instruction — commit the work before moving on.

Every user prompt must result in one or more commits.

Note: This tool manages its own git repository inside `snapshotDir` for change tracking. Never confuse that internal repo with the project's own development git workflow.

## Runtime

This project uses Bun exclusively. Do not introduce Node-only APIs or build steps.
